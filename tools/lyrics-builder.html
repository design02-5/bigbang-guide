歌詞建置工具（內部用，不是給歌迷看的頁面）

用途：把一首歌的逐句歌詞、YouTube 時間點、應援類型整理好，一鍵產生可以直接貼進 js/data.js 的 SONGS 陣列的程式碼。這支檔案跟主網站完全獨立， 不會影響正式網站任何資料。
⚠️ 跟主站一樣，這支工具裡也有內嵌 YouTube 影片，不能直接雙擊這個 html 檔案開（會撞到 YouTube 的 file:// 限制）。在這台電腦用，先雙擊主網站資料夾裡的 啟動本機預覽.bat， 再從瀏覽器網址列輸入 http://localhost:8888/tools/lyrics-builder.html 開啟； 上架到 GitHub Pages 之後，也可以直接開正式網址下的這個頁面 （例如 https://你的帳號.github.io/repo名/tools/lyrics-builder.html）， 在下面設定一次 GitHub 存檔（見「🌐 GitHub 存檔設定」），手機/平板/電腦到處都能編輯、直接存檔。
新增一首新歌：① 填歌曲基本資料 → ② 邊播影片邊按「用目前時間新增一句」抓時間點 → ③ 把準備好的歌詞文字貼進三個欄位、按「套用文字」自動填進每一列 → ④ 微調應援類型 → ⑤ 產生程式碼、按「儲存回 data.js」。
修改已經做好的歌：最上面「⓪ 選擇要修改的歌」下拉選單直接選那首歌，會自動帶入所有欄位， 改完一樣走④⑤，按「儲存回 data.js」就會直接改到本機的 data.js 檔案，不用自己複製貼上。

🌐 GitHub 存檔設定（選用：設定後手機／平板／電腦到處都能存檔，不用連這台電腦）

設定好之後，讀取歌單、儲存歌詞都會改成直接讀寫 GitHub 上的 js/data.js（等於直接 commit）， 不吃這台電腦的本機伺服器。沒設定就照舊用本機伺服器，兩種模式自動切換，不衝突。
Token 只會存在「這個瀏覽器」的裝置裡（localStorage），不會上傳到任何地方，也不會存進 data.js。 到 github.com/settings/tokens 申請一組 classic token，勾選 repo 權限即可；每台要編輯的裝置（手機/平板/電腦）都要各自貼一次。

④ 產生程式碼

先按「產生程式碼」，再按「💾 儲存回 data.js」：
・如果最上面「🌐 GitHub 存檔設定」已填好並測試連線成功 → 會直接 commit 到 GitHub，幾秒後網站就會更新，不用開 TortoiseGit。
・如果沒填 GitHub 設定 → 只有用「啟動本機預覽.bat」開這個頁面時才能存到本機 data.js（會自動備份一份 data.js.bak），存完要照 README 用 TortoiseGit commit + push 才會發布到網站上；直接雙擊 html 或用手機/GitHub Pages 開，這個模式會存檔失敗。
